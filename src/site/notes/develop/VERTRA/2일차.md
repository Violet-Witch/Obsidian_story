기본적으로 10:30:60 색조합을 따랐습니다
기본 글씨는 일단 보여야되니까 대충 흰색~회색 사이에서 고른듯

포인트컬러(10)
- rgb(218, 13, 64)
- 별 이유는 없고 백예훈 눈 색입니다

배경색1(30)
- rgba(15, 20, 50, 0.5)
- 남색입니다.
- 네비게이션 바 색.

배경색2(60)
- rgb(10, 10, 10)
- 바탕 검정색입니다.
- 방산업체 분위기가 밝은것도 웃기잖아.

#### [내부 함수성 뷰 작성]
뭔가 작동은 해야겠죠? 예 그거 만들겁니다.
`base/views.py`를 수정합니다.
```python
from django.shortcuts import render
from .models import Post 

def home(request):
    """
    메인 히어로 페이지를 렌더링합니다.
    """
    return render(request, 'base/home.html')

def about(request):
    """
    회사 소개 페이지를 렌더링합니다.
    """
    return render(request, 'base/about.html')

def defense(request):
    """
    Defense & Space(무기 및 우주 기술) 페이지를 렌더링합니다.
    """
    return render(request, 'base/defense.html')

def business(request):
    """
    사업 분야 페이지를 렌더링합니다.
    """
    return render(request, 'base/business.html')

def security(request):
    """
    보안 페이지를 렌더링합니다.
    """
    return render(request, 'base/security.html')

def news(request):
    """
    최신 뉴스 페이지를 렌더링합니다.
    """
    return render(request, 'base/news.html')

def community(request):
    """
    방명록 기능이 이전된 커뮤니티 페이지입니다.
    DB에서 모든 게시물을 가져와 전달합니다.
    """
    posts = Post.objects.all().order_by('-created_at')
    return render(request, 'base/community.html', {'posts': posts})

def careers(request):
    """
    채용 정보 페이지를 렌더링합니다.
    """
    return render(request, 'base/careers.html')

def contact(request):
    """
    연락처 및 문의 페이지를 렌더링합니다.
    """
    return render(request, 'base/contact.html')
```

## [4. 네비게이션 바 적용 & 커뮤니티 탭 작성]

#### [네비게이션 바 적용]
만든 html 문서들 맨 위에 다음과 같은 코드를 적용합니다.
```html
{% extends 'base/base.html' %}
```
다 적용하셔야 합니다.

#### [커뮤니티 탭 작성]
대충 모양만 잡아두는 겁니다. 수정에 수정을 할 예정입니다.
`community.html`에 다음과 같은 코드를 적용합니다.
```html
{% extends 'base/base.html' %}

{% block title %}커뮤니티 - VERTRA{% endblock %}

{% block content %}
    <div class="community-container">
        <div class="page-header">
            <h1>커뮤니티</h1>
            <p>VERTRA 임직원용 공개 게시판입니다.</p>
        </div>

        <div class="post-list">
            {% for post in posts %}
                <div class="post-box">
                    <div class="post-header">
                        <h3>{{ post.title }}</h3>
                        <small>{{ post.created_at|date:"Y-m-d H:i" }}</small>
                    </div>
                    <div class="post-body">
                        <p>{{ post.content }}</p>
                    </div>
                </div>
            {% empty %}
                <div class="empty-state">
                    <p>아직 작성된 글이 없습니다. 첫 번째 글을 남겨보세요.</p>
                </div>
            {% endfor %}
        </div>
    </div>
{% endblock %}
```
